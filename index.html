选题1：五中全会开幕：十五五规划建议定调，利率换锚与国资创收的暗线

📐 大周期定位：10/26 二十届五中全会（10/26-29）开幕，审议未来五年规划建议；这是政策定调的最高信号源，市场聚焦新质生产力、内需与安全主线。利益分析法穿透：表面是规划建议，底层是利率锚切换（LPR长期持平）+国资创收（拉升股市高位减持补财政）的延续。

一、核心事件与利益格局

表象

二十届五中全会 10/26-29 在京召开，审议《十五五规划建议》。市场预期围绕新质生产力、内需扩张、战略安全（粮食/能源/矿产/芯片）三大主线，公报 10/29 发布。

利益相关方与利益链条

  • 国家层（最高优先）：用规划建议锁定未来五年产业与安全坐标，把“新质生产力”从口号变成国资主导的投资赛道。
  • 国资/财政层：规划建议落地 → 国资改革细则 + 战略方向题材质地 → 拉升相关国资筹码 → 高位减持变现补财政缺口（时老师“国资创收逻辑”）。这是一条从政策制定者到国资减持者的完整利益链。
  • 民资/散户层：跟着政策题材料博弈，是最终买单者——追高被套的剧本在每一轮规划行情都重演。

关键买单者

散户与民资。规划建议的“预期红利”在公报前已被部分定价，公报发布后往往是“利好兑现即出货”的节点。

推演

五中全会后部委配套文件 + 国资改革细则预期升温，A股结构机会围绕“国资 + 战略方向”（战略金属/高端制造/安全主线）。但利率锚未变：LPR 1年期3.00%/5年期3.50%连续16个月持平，降息预期落空，靠结构性工具滴灌，意味着规划红利是“结构牛”而非“水牛”。

趋势判断

强化。规划建议是未来五年政策母本，但短期节奏上“公报前预期炒、公报后兑现”的历史规律不变。

二、投资部分

  • A股：围绕国资 + 战略金属/新质生产力做结构，不追高题材末端的纯概念票；等公报后回调再介入更稳。
  • 风险：规划建议若低于预期（无增量财政/货币），预期落空回撤；止损以板块放量滞涨为信号。
  • 逻辑锚：国资创收 + 利率换锚双线并进，资源为王（稀土/锑/钛/铀）仍是规划建议的长期受益方向。

表象

关键买单者

美国纳税人 + 全球美债持有者。利率每升1bp，财政部年化利息支出多几十亿美元；新兴市场为美元融资成本买单。

推演

Fed 按兵不动但口风偏鹰（提及油价通胀风险）→ 10Y守5%；若核心PCE(10/29)反弹则加息定价再升。ECB 关注法国主权风险措辞；BOJ 在158日元附近纠结加息。本周是“声明市”，波动在口风而非数字。

趋势判断

僵局偏鹰。利率高位平台期延续，真实利率对风险资产的压制是中期常量。

二、投资部分

  • 美债：长端收益率5%附近有配置价值但波动大，非专业者慎杠杆。
  • 黄金：真实利率回升是逆风，但央行买盘 + 地缘期权托底，4000附近拉锯。
  • 美股：AI巨头估值对利率敏感，Fed口风偏鹰则纳指承压；关注10/29核心PCE。

趋势判断

僵局偏恶化。欧洲比美国更难看，资金用脚投票奔美元。
