一、核心事件与利益格局

1. 表象

特朗普公开宣称完全控制霍尔木兹（全球 1/5 海运原油咽喉）；俄美达成柴油供应协议（俄以能源合作换制裁松动）；德国开庭审理北溪管道爆炸前乌方人员；伊朗海军对霍尔木兹通航发协调警示；海湾原油出口翻倍但靠暗航规避。

2. 利益格局拆解（三层结构）

  • 国家层：美国谋求能源霸权+掐断俄欧能源联系，把霍尔木兹控制权变现为地缘筹码；俄罗斯以柴油出口换取制裁豁免、分化欧美；欧洲在「去俄能源依赖」伤口上再被北溪追责捅一刀，能源安全更脆弱；伊朗在美俄夹缝中维持海峡话语权。
  • 资本集团：美国页岩油/LNG 出口商、航运保险与原油贸易商是显性受益者；欧洲公用事业与制造业承接能源溢价；接盘暗航运力的船东赚风险溢价。
  • 民众层：全球油价中枢上移直接抬升燃油与电价，低收入国家能源账单最脆弱，是能源地缘的终极买单者。

3. 利益链条

特朗普控霍尔木兹 → 海峡通航风险溢价 → 油价中枢上移（美油已 94.79、布油 104.70）→ 俄柴油协议分流欧洲供给、削弱制裁效力 → 北溪追责坐实乌方责任、欧洲对俄谈判筹码再损 → 全球能源安全叙事回归、通胀预期反复。

4. 关键买单者

欧洲（能源自主再受挫）、全球燃油/电价消费者、依赖稳定航运的制造业为第一买单者；接盘高油价通胀的各国央行次之。

5. 推演

  • 短期：霍尔木兹「可控但不稳」，油价易涨难跌，暗航常态化推高运费与保险。
  • 中期：俄美柴油协议若落地，俄油折价优势削弱欧洲制裁同盟；北溪追责判决将重塑欧洲对乌军援民意。
  • 临界信号：霍尔木兹实际通航中断、俄柴油协议文本披露、北溪判决结果、伊朗下一步动作。

6. 趋势判断

强化。能源咽喉控制权争夺从「代理人袭扰」升级为「大国直接下场」，供给预期扰动中枢上移，油价与通胀的粘性上升。

中欧高层会晤推动稀土永磁体出口审批便利化；欧盟寻求降低对华稀土依赖，但短期内高端永磁体供应仍高度依赖中国；2025 年以来中国稀土出口管制持续加码。

2. 利益格局拆解（三层结构）

  • 国家层：中国把稀土作为对欧博弈核心筹码，换取欧盟在关税、地缘立场上的让步；欧盟推进「去风险」却被迫承认现实依赖，陷入战略两难。
  • 资本集团：北方稀土等中国稀土龙头受益于管制溢价与议价权提升；欧洲车企、风电整机商是被断供威胁压制的下游，纷纷抢囤库存。
  • 民众层：终端电动车、风电、消费电子的成本与供给稳定性受稀土走向牵动，欧洲消费者为「去风险」的代价买单。

3. 利益链条

中国收紧/精细化出口管制 → 欧洲下游恐慌性囤货、寻求替代（澳洲/美国矿+本土冶炼）但产能远未起量 → 稀土价格中枢上移、中国龙头利润与议价权双升 → 欧盟被迫回到谈判桌接受「绿色通道」式可控供给 → 筹码仍在中方手中。这是资源主权对产业依赖的压制。

4. 关键买单者

欧洲下游制造业（车企/风电）是第一买单者——为「去风险」的供应链重构与溢价库存买单；试图脱钩的替代产能投资者则承担巨额沉没成本。

5. 推演

  • 短期：绿色通道降低欧洲断供恐慌，稀土价格急涨动能缓和，但溢价中枢已在。
  • 中期：中国不会真松绑，只会「精准放行」；一旦欧方在地缘上触线，阀门随时再拧紧。
  • 临界信号：欧洲本土冶炼产能大规模投产（需 3—5 年），或中国将稀土管制扩展至更多终端品类。

6. 趋势判断

强化且可控。稀土是未来十年的中国战略王炸牌，出口管制从「数量管制」走向「客户与用途管制」，主权属性只会更强。

二、投资部分

5. 投资映射

  • 稀土/永磁龙头（北方稀土等）：受益于管制溢价与议价权，是资源为王主线核心。
  • 锑/钛/铀等中国可主导的战略金属：同属资源为王逻辑，与稀土形成组合。
  • 规避：欧洲「去风险」概念下的高估值替代冶炼标的（产能兑现远、不确定性大）。
  • 黄金/白银：独立货币属性，长期底仓。

6. 风险提示

  • 误判「绿色通道=全面松绑」：实为精准杠杆，阀门随时可紧。
  • 全球衰退压低工业金属需求 → 稀土亦受拖累。
  • 替代技术（无稀土电机）突破的尾部风险。

7. 核心观察指标

  • 中国稀土出口配额与永磁体出口批文节奏。
  • 欧洲稀土库存天数与本土冶炼投产进度。
  • 氧化镨钕/金属镨钕现货价格（SMM/百川）。
  • 欧盟对华关税与地缘立场的联动。
