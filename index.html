第二层 机制：现代灾害伤亡结构已变——建筑抗震标准提升压低原生伤亡，但基础设施（水、电、医疗、燃料）脆弱性把伤亡后移至次生阶段。抗震越好，次生占比越高。
第三层 利益：救灾资源最优配置应从「搜救」前移到「供水、供电与医疗连续性」。当前应急预算与演练仍普遍以搜救为中心。
第四层 长期：极端高温与地震叠加成可预期复合场景，抗灾投资重点将从建筑结构转向生命线工程——供水管网抗震化、区域医院独立供电、燃料储备下沉。这条被伤亡数字掩盖的长期资本开支主线，规模远大于灾后重建本身。

4. 传导路径

干预 → 日元空头平仓 → 美元走弱 → 进口成本下降 → 日本输入型通胀缓解 → 日银加息约束松动；同时美元弱 + 油价落 → 全球输入型通胀压力同步减轻 → 美联储降息空间打开。汇率、油价、利率三条链在「地缘风险回吐」这一节点汇流。

5. 情景推演

情景A（干预见效+利差收窄）：日元温和升值、美元偏弱，全球风险资产获双重支撑，AI融资成本压力缓解。
情景B（利差刚性、干预失效）：美日货币政策分化未消，日元贬值趋势复燃，干预仅延缓不改向，进口通胀回潮。
情景C（地缘再升温）：美伊谈判破裂、油价反弹，避险买盘推升美元、日元再度承压，干预成本陡增。

6. 暗线（三条）

第一层 现象：美日15年来首次联手干预，却由特朗普定义为「友谊」。
第二层 机制：弱美元同时服务美日双方——美方缓解通胀、日方稳住汇率，这是罕见的利益重合点；但「友谊」叙事削弱了干预的市场可信度。
第三层 利益：干预真正的对手是庞大的套息交易存量。谁能提前知悉协调时点，谁能在平仓前调整头寸——信息优势在汇市与在油市等价。
第四层 长期：当汇率成为地缘风险的二次分配工具，单一咽喉（能源）与单一货币（美元）的脆弱性被同步暴露。结果不是咽喉被绕开，而是绕行能力本身被资本化——管道、替代港口、本币结算、北极航线估值逻辑因此改写，这条主线比这场干预活得更久。
