选题1：四十八小时反转：从「二战以来最猛烈轰炸」到「取消打击」，油价暗盘闪崩6.8%意味着什么

> 📐 大周期定位：地缘冲突定价从「战争溢价累积」急转为「溢价回吐」——周末48小时无交易窗口内完成方向反转，周一开盘的跳空方向由向上翻为向下

1. 事件链追踪

7月31日 戴维营内阁会议：特朗普对媒体称美国将「狠狠打击」伊朗，「总有一天他们会说我们再也撑不住了」。消息人士称会议讨论了军事计划，美以准备对伊朗能源基础设施发动迄今最猛烈的轰炸，发电厂与炼油厂为主要目标，行动可能持续整个周末。（新华社 · 央视）

2. 利益格局拆解

美方：三重现实约束促成收手——海湾盟友明确反对、参联会评估空袭无法达成全部战略目标、国内不支持卷入全面战争。核心诉求始终是「以战逼降」而非真打，这已是战事爆发以来第三次临门收手。
沙特与海湾国家：最怕的不是伊朗被打，而是伊朗报复自己的能源命脉。美国推进「沙以双支轴」战略、推动亚伯拉罕协议扩容的目标，决定了必须回应盟友诉求。真正制约白宫的是盟友的资产负债表，不是伊朗的反击能力。
伊朗：公开否认「请求停战」，是在保全谈判姿态与国内合法性。它需要的是「美国因惧战而收手」的叙事，而非「伊朗求和」的叙事。这决定了协议框架短期内很难获得德黑兰的公开背书。
多空双方：上周五收盘时市场为「开打」定价，周日下午被迫为「停手」定价。中间隔着48小时无法交易的窗口——这是本轮最真实的利益转移：谁在周五收盘前押注了方向，谁在周一开盘承担全部结果。

3. 供需格局（硬数据支撑）

价格侧硬数据：上周五结算价布伦特90.12美元/桶（+1.22%）、WTI 84.67美元/桶（+1.29%）；7月全月布伦特累涨23.59%、WTI累涨21.83%，均为3月以来最大单月涨幅，月初布伦特尚不足72美元。周末暗盘布伦特先破91美元后跌至83.93美元，日内振幅超8%。（新华社 · 金十数据 · Reuters）
运输侧硬数据：海峡日通行船舶量由22艘骤降至5艘，单日降幅77%，5艘全经伊朗一侧航道；中东至远东VLCC运费达480,287美元/天（WS 450点），周涨14%；VLCC平均运价17.29万美元/天，周涨19%。（Reuters · LSEG数据）
供给侧的反向证据：沙特8月官方售价定为贴水1.50美元/桶，创2003年以来最大降幅；OPEC+批准9月增产18.8万桶/日后暂停增产至年底。产油国自身的定价行为并不支持长期高油价，这是价格结构中最被忽视的看空腿。
需求与库存维度：EIA原油库存截至7月24日当周录得减少716.7万桶，远超预测的减少127.2万桶；贝克休斯石油钻井数截至7月31日当周为451座。库存去化真实，但去化速度不足以独立支撑23%的月涨幅——月度涨幅中的绝大部分是风险溢价，而非基本面。
历史锚点：2019年沙特阿美Abqaiq设施遇袭当日布伦特单日跳涨约15%，因产能迅速恢复，价格在约两周内基本回吐。地缘溢价的回吐速度通常快于累积速度，因为累积依赖持续的新闻流，回吐只需要一条否定消息。本轮溢价累积用了整月，而抹去其中三分之一只用了一个周日下午。

4. 传导路径

打击取消 → 风险溢价回吐 → 原油与成品油裂解价差收窄 → 航运战争险附加费见顶（但滞后回落） → 进口国输入型通胀压力减轻 → 美联储9月降息约束松动 → 高估值成长股贴现率下行。注意这条链的末端同样落在AI板块：油价下行反而缓解了已经紧绷的AI融资成本压力，这是周末最容易被忽略的正向溢出。

5. 情景推演

情景A（德黑兰在开盘前默认框架）：油价周一低开后震荡，溢价在一周内回吐大半，全球风险资产获得喘息，AI信用曲线同步缓和。
情景B（协议流产、打击重启）：暗盘跌幅被全额修复甚至反超，布伦特重回95美元上方，本轮将是第三次「狼来了」之后的第一次真狼，市场的信任折价会让反弹更加剧烈。
情景C（长期拉锯，通行权反复被用作筹码）：概率最高的中性路径——海峡状态在「关闭」与「有条件通行」之间反复，油价被锁定在85至100美元区间震荡，VLCC运费维持高位，航运与保险成为最稳定的受益方。
共同点：无论哪种情景，运费与保险的正常化都显著滞后于价格，这决定了航运板块的盈利兑现比油价走势更具确定性。

6. 暗线（三条）

第一层 现象：白宫在军力集结完成、使馆预警已发出之后，突然宣布收手。
第二层 机制：军事决策已被完整纳入市场与盟友影响评估流程——先看油价、再看沙特、最后看中期选举。军事威慑的真实目的是压低对手的谈判底线，而非改变地面态势。
第三层 利益：能提前掌握时间表的机构，可在周五收盘前完成头寸布置。上周五油价上涨而黄金下跌的组合，事后看是「押注供给中断、不押注系统性恐慌」的精确表达——而周日的闪崩说明这批头寸已在暗盘中撤离。
第四层 长期：当「威胁—收手」成为可复用的常规操作，市场对同类消息的反应函数会持续衰减。下一次真正的打击到来时，价格反应可能显著弱于本次——这才是反复喊狼来了最危险的地方，它会系统性地压低真实风险的定价。

选题2：CDS全线破纪录之后的第一次回落：2,360亿债务对上负410亿现金流

> 📐 大周期定位：AI信用周期领先股权周期见顶——CDS作为机构风险定价的领先指标全线创纪录后出现首个回落信号，2,360亿美元AI债务与转负的自由现金流正在赛跑

1. 事件链追踪

7月27日：英伟达五年期CDS单日一度上涨约14个基点、最高升至约82个基点，为该合约去年11月开始活跃交易以来最大盘中升幅。同日Alphabet升至67个基点历史新高。（Bloomberg · ICE Data Services数据）
7月28日：伦敦证券交易所集团数据显示，甲骨文、SpaceX、Alphabet、亚马逊、Meta、博通、英伟达关联CDS报价均升至历史纪录高位。甲骨文五年期CDS报215个基点，年初仅144个基点。标普全球评级将甲骨文下调至BBB-，仅比垃圾级高一档。
7月28日 同期：CoreWeave五年期CDS一度突破855个基点，按主流定价模型隐含五年违约概率接近50%。
7月30日：各家科技巨头CDS出现小幅回落，为本轮走阔以来第一个方向性缓和信号。（格隆汇 · 财联社援引券商研究）
本周：贝莱德发行125亿美元债券为Meta得州数据中心融资，票面收益率7.53%，是本轮AI融资热潮开启以来蓝筹数据中心债券收益率最高的案例之一。亚马逊本月250亿美元债券发行认购规模仅略高于发行规模，而此前大型科技公司发债通常获约4倍超额认购。

2. 利益格局拆解

谁在买保险：CDS买方是持有这些公司债券的大型机构。CDS飙升不是散户情绪，而是专业机构真金白银为持仓加保的行为，属客观风险定价。
谁在转移风险：银行往往利用CDS市场转移相关信用风险；投行与结构化产品发行方通过表外载体把债务从科技巨头资产负债表上移出，赚取结构化费用。Meta项目中贝莱德持股80%、Meta仅保留约20%权益并提供租赁付款担保——风险从股东转移到了债权人与结构化载体。
分化正在加速：Miller Tabak首席市场策略师指出，信贷市场正在AI竞赛中挑选赢家和输家，而被视为「输家」的企业数量正在不断增加。微软CDS仍处30至60个基点低位，甲骨文已到215、CoreWeave到855——同一个赛道内的信用定价已相差十余倍。

3. 供需格局（硬数据支撑）

资金需求侧硬数据：摩根士丹利统计，截至今年5月全球为AI项目融资发行的债务约2,360亿美元，超过去年同期发行规模的四倍。资金正涌向欧洲投资级债券、美国商业抵押贷款支持证券以及杠杆贷款市场。
现金流供给侧硬数据：FactSet口径显示，五大超大规模云厂商（Alphabet、亚马逊、Meta、微软、甲骨文）合计自由现金流将从2025年的1,870亿美元降至今年的负28亿美元，2027年预计进一步降至负410亿美元。需求端在放量，内生供给端在枯竭，差额只能由债市补。
融资成本硬数据：甲骨文2054年到期债券收益率升至7.8%（较年初上行接近1个百分点）；科技巨头10年期债券融资利率区间为4.83%至5.90%，发行利差50至145个基点，其中甲骨文145、SpaceX 140为最高，英伟达50、Alphabet 63为最低。亚马逊3月发行的10年期债券利差75个基点，7月发行升至80个基点。
产能与库存维度：数据中心是重资产、长周期投入，一旦融资中断，在建产能立即变成沉没成本。与存储芯片可通过砍单快速调节不同，数据中心没有快速去库存的机制，这是信用风险的天然放大器。区域上，算力的物理承载正在向马来西亚柔佛外溢，该州去年吸引新增投资约1,100亿林吉特；新加坡贸工部则明确将「AI相关资本支出突然回落」列为全年增长的三大下行风险之一。（联合早报 · 格隆汇）
历史锚点：2000年电信资本开支泡沫中，光纤需求预测本身并无大错，崩塌发生在融资成本上行与现金回报周期拉长的交汇点。2008年危机中CDS并非风险起因，却是最致命的加速器——保险成本上行迫使机构降低持仓，抛售又推高保险成本，形成正反馈。当下855个基点的读数，已进入当年问题机构的量级区间。

4. 传导路径

CDS走阔 → 债券收益率上行 → 新增融资成本抬升 → 高杠杆算力企业被迫收缩资本开支 → 上游GPU与存储订单下修 → 整个AI资本开支链条同步降速。链条起点在信用市场，而非股票市场。反之，7月30日的CDS回落若能延续，配合油价溢价回吐带来的利率环境改善，这条链也可能反向走一遍。

5. 情景推演

情景A（回落延续）：地缘降温+通胀回落推动利率下行，AI信用利差收窄，融资窗口重开，资本开支周期获得延长。
情景B（背离继续扩大）：股价上涨而CDS重回升势，最终以某家高杠杆算力企业再融资失败为触发点，风险一次性释放。CoreWeave正在贷款市场寻求26亿美元融资，是最直接的观察窗口。
情景C（政策介入）：若AI基建被认定为战略基础设施，可能出现政策性融资支持人为压低信用利差。境内债券市场「科技板」累计发行科技创新债券超2.8万亿元，某种意义上已是这条路径的先行样本。

6. 暗线（三条）

第一层 现象：CDS全线创纪录后，7月30日出现第一次集体回落。
第二层 机制：CDS是保险价格，保险价格回落有两种可能——风险真的降低了，或者承保方觉得保费已足够丰厚而愿意加大供给。区分这两者的唯一办法，是看债券一级市场的认购倍数：亚马逊250亿发行仅略超额，说明是后者。
第三层 利益：在如此高的点位仍有充足流动性，是因为CDS卖方在收取创纪录保费。若违约不发生，这是本轮最赚钱的交易之一；这批承保方与买保险的机构，往往是同一批投行的不同台子。
第四层 长期：当AI基建债务规模足够大，其信用风险将不再是行业问题，而是宏观问题。2008年的起点，也是一个「被认为不会出事」的资产类别。当下唯一的不同是这次的抵押品是电力、土地与芯片，而非住房——它们的残值曲线更陡峭。

选题3：通行权定价：5艘船、48万美元日租金，与被排在核威胁前面的那句话

> 📐 大周期定位：航道通行权取代核问题成为地缘博弈的核心标的——海峡从地理概念变为可交易的定价权，运费与保险成为比油价更稳定的受益变量

1. 事件链追踪

7月31日：伊朗「波斯湾海峡管理局」声明称，由于美军在相关海域持续采取侵略性行动，霍尔木兹海峡已无法正常通行；待地区局势恢复稳定后，官方将按申请顺序重新评估并陆续发放通行许可。（央视）
7月31日 同日：伊斯兰革命卫队声明称在该水道击中并扣留两艘违反禁令的油轮，这两艘船试图在美军护航下无视警告通过，另有四艘在警告后迅速改变航向返回。美军中央司令部则称海峡「依然开放、伊朗不控制海峡」，但已改变约30艘商船的航行路线。（半岛电视台 · Reuters）
7月31日 航运安全：一艘于7月27日左右在卡塔尔装载货物的液化天然气运输船，在通过该水道时遭投射物击中，当日在西侧入口附近停止发送讯号；英国海事贸易办公室同日发布另一份油轮附近水域发生爆炸的警告。（Reuters · 金十数据）
8月1日：特朗普宣布的协议框架中，「立即、全面、彻底开放霍尔木兹海峡」被置于「消除伊朗核威胁」之前。（新华社）
8月2日：伊朗军方消息人士强调，只要美国继续敌对行动，海峡将继续关闭，船舶只能通过已公布航线并须获革命卫队海军许可。（新华社）

2. 利益格局拆解

伊朗：战事爆发以来被迫将通行权作为筹码，客观上取得了远超预期的议价效果——它使美国的核心诉求从「核」转移到了「航道」。通行权比核设施更好用，因为它可以按天、按船、按许可逐份出售。
美国：护航成本高昂且风险巨大，地面控制海岸线在政治上不得人心。美方分析师指出的可选方案包括夺取承担伊朗九成石油出口量的哈尔克岛，或由海军实施护航但须先清除水雷——每一个选项的代价都高于谈判。
海湾产油国：卡塔尔是全球最大LNG出口国之一，其货物必须经该水道。卡塔尔斡旋人员分别同伊朗外长、美国总统特使及阿曼官员会谈，力求恢复正常通航——最积极的调停方，往往是敞口最大的一方。
船东与保险人：本轮最确定的受益方。运费与战争险附加费上行是即期收入，而风险由货主与保险人承担。

3. 供需格局（硬数据支撑）

通行量硬数据：日通行船舶量由22艘骤降至5艘，单日降幅77%，且5艘全部经伊朗一侧航道通过。（国际航运平台数据）
运输成本硬数据：中东至远东VLCC运费达480,287美元/天（WS 450点），周涨14%；VLCC平均运价17.29万美元/天，周涨19%。（Reuters · LSEG数据）
通过量的量级：该水道每日承担约1,500万至2,000万桶原油通行，全球约三分之一的液化天然气贸易亦经此。这是全球唯一没有实质替代路线的能源咽喉。
价格与港口维度：沙特8月官方售价定为贴水1.50美元/桶，创2003年以来最大降幅——在通行受阻的同时下调售价，反映的是卖方为保住亚洲买家份额而主动让利，与地缘溢价方向完全相反。港口侧，绕行好望角将使中东至远东航程增加约两周，这部分成本已计入当前运价。
历史锚点：1980至1988年两伊战争「油轮战」期间，双方累计袭击数百艘商船，最终以美国「诚意行动」护航告终，海湾航运保险费率在冲突高峰期上涨数倍并在停火后花费一年以上才回归常态。保险与运费的正常化滞后于政治解决，通常以季度而非周计。这是判断本轮航运板块盈利周期的关键参照。

4. 传导路径

通行受阻 → 运费与战争险上行 → 到岸成本抬升 → 亚洲炼厂采购成本上升 → 成品油价格传导 → 输入型通胀。同时，卖方为保份额下调官方售价，部分对冲了到岸成本上行——这解释了为何在通行量骤降77%的同时，油价的绝对涨幅仍只有月度23%量级，而非危机式的翻倍。

5. 情景推演

情景A（通航迅速恢复）：运费在数周内回落，但保险费率的回归会明显更慢，船东在这段时间窗内维持超额收益。
情景B（有条件通行长期化）：许可制成为常态，通行量在低位波动，运费维持高位，航运成为最稳定的结构性受益方。这是当前概率最高的路径。
情景C（冲突重启并波及卡塔尔LNG）：全球三分之一LNG贸易受阻，欧亚天然气价格重估，影响远超原油。这是尾部但非零概率的情形。

6. 暗线（三条）

第一层 现象：协议框架把海峡开放排在了核威胁之前。
第二层 机制：这是一次公开的议题优先级重排——美国承认，眼下最紧迫的不是伊朗的核能力，而是全球能源物流的通畅。地理咽喉的定价权，第一次在正式表述中压过了核不扩散。
第三层 利益：谁掌握通行许可的发放权，谁就获得了对全球三分之一LNG与两成原油的隐性征税能力。伊朗要的从来不只是解除制裁，而是这项权力被事实承认。
第四层 长期：本轮之后，所有依赖单一咽喉的能源与商品贸易都会被重新评估韧性溢价。结果不是航道被绕开，而是绕行能力本身被资本化——管道、替代港口、LNG接收站、乃至北极航线的估值逻辑都会因此改写。这条产业迁移主线，会比这场战争活得更久。

受灾居民：最尖锐的矛盾不是房屋倒塌，而是断水与酷暑的叠加。八代市行政机构表示急需水、食品、简易厕所与高龄者用品；一名基层课长直言「没有饮用水、无法清洗身体，加上高温酷暑，高龄者将会有生命危险」。
地方政府与医疗系统：45所医院停诊意味着医疗系统在伤亡爬升期反而失能，这是次生伤亡的核心机制。
能源与物流：灾区沿途加油站汽油普遍售罄，居民因房屋受损选择车内过夜却不敢用车——燃料短缺同时切断了避难与就医两条通路。
文化与旅游资产：有340年历史的古迹松滨轩墙体屋顶大面积坍塌，属不可逆损失。

人员与设施硬数据：遇难38人、避难9,226人、避难所210处、受损房屋3,851栋、停电约4.7万户、停诊医院45所、有感余震超300次。（央视 · 中青报，8月2日通报）
生活物资供给缺口：饮用水、面包等免烹饪食品、简易厕所、高龄者与婴幼儿用品为当前四类硬缺口。基层反馈「持续性断水，民众连冲泡面的水也没有」，说明供给缺口已下探到最基础的层级。
燃料供给：灾区加油站汽油售罄，这是运输链在末端的完全断裂——比干线中断更难通过调度解决。

4. 传导路径

主震 → 房屋与管网受损 → 断水断电 → 医院失能 + 高温 → 关联死爬升 → 避难期延长 → 区域消费与生产同步停滞 → 供应链局部中断。关键节点在「医院失能」：它把一场地质灾害转化为公共卫生事件，而后者的伤亡曲线比前者长得多。

5. 情景推演

情景A（供水一周内恢复）：关联死增速放缓，避难人数快速下降，区域生产在两周内基本复原。
情景B（断水延续+高温持续）：气象预报显示当地气温或达40摄氏度量级，若供水恢复缓慢，关联死将成为死亡数字的主要增量，避难期拉长至月度。
情景C（发生同量级余震）：气象厅已明确警示需警惕余震。若再遇强震，抢修进度归零，影响将从区域外溢至九州整体的产业链排程。

6. 暗线（三条）

第一层 现象：震后第五天，死亡人数仍在上升。
第二层 机制：现代灾害的伤亡结构已经改变——建筑抗震标准提升大幅压低了原生伤亡，但基础设施（水、电、医疗、燃料）的脆弱性把伤亡后移到了次生阶段。抗震做得越好，次生占比越高。
第三层 利益：这一结构性变化意味着救灾资源的最优配置应从「搜救」前移到「供水、供电与医疗连续性」。而当前的应急预算与演练体系，仍普遍以搜救为中心。
第四层 长期：当极端高温与地震叠加成为可预期的复合场景，抗灾投资的重点将从建筑结构转向生命线工程——供水管网抗震化、区域医院独立供电、燃料储备下沉。这是一条被伤亡数字掩盖的长期资本开支主线，其规模远大于灾后重建本身。半岛电视台在报道中东能源基础设施遇袭时提出的同类命题——电网与炼厂的修复周期远长于打击本身——在这里得到了非战争场景下的印证。
