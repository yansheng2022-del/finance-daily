2. 利益格局拆解

（主要原因）Moderna / 默沙东：这是「技术范式」卡位——把mRNA从传染病疫苗升维到肿瘤治疗，打开数千亿美元级新市场、重塑全球药企估值逻辑；默沙东借K药组合把mRNA变成自家PD-1的「延长线」，锁定肿瘤免疫生态位，是本轮突破的主导方与最大受益方，用一项临床把「概念」折算成「先发卡位租金」。

（次要原因）国内药企 / 监管（CDE·医保）：国内管线尚在早期（I/II期），与海外III期差距明显，但「国产替代 + 创新药入医保十五五规划」叙事提供政策想象空间；CDE与医保是放行节奏与支付可及性的守门人，决定国产价值能否兑现，是「审评快、支付慢」错位的两端。

3. 阈值化传导链

III期阳性 → 估值逻辑重构（从「概念」到「成药性验证」）→ NBI+6.39% → A股映射涨停（创新药-3.78%为事件后回吐阈值）；下一阈值 = 临床读出 / BD授权落地，任一读出即触发重估。
产能/产量（供给维度关键词）：个性化「一人一制」生产瓶颈（每批次重耗一套mRNA原料+核心酶）是放量核心约束；递送系统LNP（脂质纳米粒）与基因测序产能决定「实验室突破」能否转为「可量产疗法」，也是国产替代的真实门槛。

4. 商业行为反推政策

药企加速BD授权/合作（英矽智能×元码智药AI+mRNA），商业行为反向倒逼监管加快审评；国内「十五五」医保支持创新药入医保，政策为估值背书。但支付端（商保/医保）对高值创新药仍审慎，形成「审评快、支付慢」的结构性错位，商业预期跑在支付能力之前。

5. 供需格局与历史锚点

供需格局：肿瘤治疗「需求（全球数千万癌症患者）vs 供给（个性化疫苗产能，一人一制瓶颈）」极度错配，产能与支付是两大核心约束；mRNA原料（核苷酸/加帽酶）、LNP递送、基因测序构成供给三角，三者任一短缺都卡住商业化咽喉。
历史类似：2018年CAR-T（Kymriah等）开启细胞治疗范式、PD-1当年重塑肿瘤免疫；本次更像mRNA肿瘤疫苗「从0到1的范式突破」，但商业化瓶颈（成本极高、一人一制无法批量铺货、依赖肿瘤科医生精准推荐、医保商保支付挑战）使其短期难规模化，类似基因治疗的高价可及性难题。
